# My neighborhood

好きなアルバムを、ひとつの街に。

## 起動方法（Windows）

1. このフォルダ内の `start.bat` をダブルクリック
2. ブラウザで `http://localhost:3000` が開く
3. アーティスト名を検索
4. アーティストを選ぶ
5. アルバムを選ぶとジャケットが街に追加される

※ `public/index.html` を直接ダブルクリックしないでください。

## データについて

アーティスト・アルバム情報は MusicBrainz API、ジャケット画像は Cover Art Archive を利用しています。


追加機能:
- 「結果を保存」でコラージュをPNG保存
- 「Xに投稿」で画像共有対応端末では画像＋#myneighb0rhoodを共有
- PCなど非対応環境ではPNGを保存してX投稿画面を開く
